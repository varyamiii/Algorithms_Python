# Домашнее задание 1

## Задача 1. Палиндром

### Описание

Функция is_palindrome сохраняет исходное число, а затем полностью
переворачивает его. На каждом шаге последняя цифра извлекается операцией
% 10, добавляется в reversed_number, а из обрабатываемого числа удаляется
с помощью // 10. Строки для проверки числа не используются. В конце
исходное и перевёрнутое числа сравниваются.

После завершения цикла reversed_number содержит цифры исходного числа в
обратном порядке. Поэтому равенство original_number == reversed_number
выполняется, когда число является палиндромом.

### Оценка сложности

**Сложность:** время - O(log n), потому что количество действий равно
количеству цифр числа; дополнительная память - O(1).

### Визуализация

Визуализация для 12321:

| Шаг | Оставшаяся часть числа | Перевёрнутое число |
|---:|---:|---:|
| 0 | 12321 | 0 |
| 1 | 1232 | 1 |
| 2 | 123 | 12 |
| 3 | 12 | 123 |
| 4 | 1 | 1232 |
| 5 | 0 | 12321 |

Получаем исходное число 12321 и перевёрнутое число 12321. Они равны,
следовательно, число является палиндромом.

### Тесты

Файл palindrome/test_task_1.py проверяет число с нечётным и чётным
количеством цифр, непалиндром, однозначное число, число с нулём в конце и
нулевое значение.

Запуск программы из корня репозитория:

```bash
python -m homework_1.palindrome.task_1
```

После запуска программа просит ввести одно целое положительное число. Нужно
ввести его в одной строке и нажать Enter. Например: 12321.

## Задача 2. Сумма

### Описание

Поскольку все числа положительные, выгодно сначала взять их все. Если общая
сумма чётная, это максимальный ответ. Если она нечётная, для получения
максимальной чётной суммы нужно исключить наименьшее нечётное число.

Удаление чётного числа не изменит нечётность суммы. Чтобы нечётная сумма стала
чётной, необходимо удалить нечётное число. Удаление наименьшего нечётного
числа уменьшает сумму минимально, поэтому полученная чётная сумма максимальна.

### Оценка сложности

**Сложность:** время - O(n) за один проход по массиву; дополнительная
память - O(1), поскольку хранятся только сумма и минимальное нечётное число.

### Визуализация

Визуализация для [9, 2, 3, 6, 5]:

| Прочитано число | Текущая сумма | Минимальное нечётное |
|---:|---:|---:|
| 9 | 9 | 9 |
| 2 | 11 | 9 |
| 3 | 14 | 3 |
| 6 | 20 | 3 |
| 5 | 25 | 3 |

Сумма 25 нечётная, поэтому исключаем 3: 25 - 3 = 22.

### Тесты

Файл sum/test_task_2.py проверяет единственное нечётное число, только чётные
числа, чётную и нечётную общую сумму, а также пустой массив.

Запуск программы из корня репозитория:

```bash
python -m homework_1.sum.task_2
```

После запуска нужно ввести все положительные целые числа в одной строке через
пробел и нажать Enter. Например: 1 3 8 34 6 17.

## Задача 3. Простые числа

### Описание

Функция count_primes перебирает все числа от 2 до N - 1. Для каждого числа
функция is_prime проверяет делители начиная с 2. Если число делится без остатка,
оно является составным. Если ни одного делителя не найдено, число является
простым и счётчик увеличивается на один.

Проверять делители больше квадратного корня не требуется. Если число составное,
хотя бы один из двух его множителей не превышает квадратный корень. Поэтому
делитель составного числа обязательно будет найден. Число N не проверяется,
так как по условию нужно посчитать только простые числа меньше N.

### Оценка сложности

**Сложность:** время - O(N * sqrt(N)), потому что проверяются N чисел и для
каждого может потребоваться до sqrt(N) проверок делителей. Дополнительная
память - O(1), потому что программа хранит только несколько числовых переменных.

### Визуализация

Визуализация для N = 12:

| Проверяемое число | Проверки деления | Результат | Счётчик |
|---:|---|---|---:|
| 2 | делители не проверяются | простое | 1 |
| 3 | делители не проверяются | простое | 2 |
| 4 | 4 % 2 = 0 | составное | 2 |
| 5 | 5 % 2 = 1 | простое | 3 |
| 6 | 6 % 2 = 0 | составное | 3 |
| 7 | 7 % 2 = 1 | простое | 4 |
| 8 | 8 % 2 = 0 | составное | 4 |
| 9 | 9 % 2 = 1; 9 % 3 = 0 | составное | 4 |
| 10 | 10 % 2 = 0 | составное | 4 |
| 11 | 11 % 2 = 1; 11 % 3 = 2 | простое | 5 |

Получен ответ 5: простыми числами меньше 12 являются 2, 3, 5, 7 и 11.

### Тесты

Файл prime/test_task_3.py проверяет обычное значение, значения около нижней
границы, строгую границу < N и более крупное значение N = 100.

Запуск программы из корня репозитория:

```bash
python -m homework_1.prime.task_3
```

После запуска программа просит ввести одно целое число N. Нужно ввести его в
одной строке и нажать Enter. Например: 20.
