# Домашнее задание 4. Binary Tree

## Задача 1. Tree Traversal

### Описание решения

`BinarySearchTree` хранит ссылку на корень дерева. При вставке значение
сравнивается с текущим узлом: меньшее значение направляется в левое поддерево,
большее — в правое. Спуск продолжается до первой свободной позиции. В этой
реализации BST является строгим: если значение уже существует, повторный узел
не создаётся.

Шесть обходов реализованы рекурсивно. Буква `N` обозначает текущий узел,
`L` — левое поддерево, `R` — правое:

- preorder — NLR;
- inorder — LNR;
- postorder — LRN;
- reverse preorder — NRL;
- reverse inorder — RNL;
- reverse postorder — RLN.

Каждая функция записывает значение узла в результирующий список в момент,
заданный соответствующим порядком, поэтому список совпадает с порядком
посещения узлов.

### Оценка сложности

Вставка занимает **O(h)** времени и **O(1)** дополнительной памяти, где `h` —
высота дерева. Для сбалансированного дерева `h = O(log n)`, в худшем случае у
вырожденного дерева `h = O(n)`.

Каждый обход посещает `n` узлов ровно один раз: время — **O(n)**, итоговый
список занимает **O(n)**, стек рекурсии — **O(h)**.

### Визуализация

После последовательной вставки `8, 3, 10, 1, 6, 14, 4, 7, 13` получается:

```text
             8
           /   \
          3     10
         / \      \
        1   6      14
           / \    /
          4   7  13
```

Например, preorder сначала посещает узел, затем левое и правое поддеревья:

```text
8 -> 3 -> 1 -> 6 -> 4 -> 7 -> 10 -> 14 -> 13
```

Результаты всех обходов:

| Обход | Порядок значений |
|---|---|
| preorder (NLR) | 8, 3, 1, 6, 4, 7, 10, 14, 13 |
| inorder (LNR) | 1, 3, 4, 6, 7, 8, 10, 13, 14 |
| postorder (LRN) | 1, 4, 7, 6, 3, 13, 14, 10, 8 |
| reverse preorder (NRL) | 8, 10, 14, 13, 3, 6, 7, 4, 1 |
| reverse inorder (RNL) | 14, 13, 10, 8, 7, 6, 4, 3, 1 |
| reverse postorder (RLN) | 13, 14, 10, 7, 4, 6, 1, 3, 8 |

### Тесты

Проверяются все шесть обходов, корректность вставки, повторное значение,
пустое дерево, дерево из одного узла, отрицательные значения и применение
функций обхода к произвольному бинарному дереву.

## Задача 2. Validate BST

### Описание решения

Недостаточно сравнить узел только с его непосредственными детьми. Каждый узел
должен удовлетворять ограничениям всех предков. Функция `is_valid_bst`
передаёт при рекурсивном спуске допустимый открытый интервал:

- для левого ребёнка верхняя граница равна значению текущего узла;
- для правого ребёнка нижняя граница равна значению текущего узла.

Если значение достигло границы или вышло за неё, дерево не является строгим
BST. Пустое дерево и дерево из одного узла корректны.

### Оценка сложности

Каждый узел проверяется один раз: время — **O(n)**. Дополнительная память стека
рекурсии — **O(h)**: **O(log n)** для сбалансированного дерева и **O(n)** в
худшем случае.

### Визуализация

```text
          8             допустимый интервал: (-∞, +∞)
        /   \
       3     10         для 3: (-∞, 8), для 10: (8, +∞)
        \
         9              для 9: (3, 8) — нарушение, 9 >= 8
```

Пошаговая проверка проблемной ветви:

| Узел | Нижняя граница | Верхняя граница | Результат |
|---:|---:|---:|---|
| 8 | отсутствует | отсутствует | корректно |
| 3 | отсутствует | 8 | корректно |
| 9 | 3 | 8 | ошибка: 9 не меньше 8 |

Хотя `9 > 3` и локальная связь с родителем выглядит верно, узел расположен в
левом поддереве `8`, поэтому всё дерево не является BST.

### Тесты

Проверяются пустое и одноузловое деревья, корректное BST, непосредственное и
глубокое нарушения порядка, повтор значения, ноль и отрицательные числа.

## Задача 3. Balanced Binary Tree

### Описание решения

`is_balanced` выполняет postorder-обход снизу вверх. Для пустого поддерева
высота равна нулю. После получения высот обоих поддеревьев функция сравнивает
их и возвращает высоту текущего узла. Значение `-1` служит сигналом, что ниже
уже найден дисбаланс; тогда дальнейшие вычисления прекращаются.

Так каждый узел одновременно участвует и в вычислении высоты, и в проверке
баланса. Повторно вычислять высоты не нужно.

### Оценка сложности

Каждый узел обрабатывается не более одного раза: время — **O(n)**.
Дополнительная память стека рекурсии — **O(h)**, то есть **O(log n)** для
сбалансированного дерева и **O(n)** для вырожденного.

### Визуализация

```text
          1
         / \
        2   5
       /     \
      3       6
     /         \
    4           7
```

Высоты вычисляются от листьев к корню:

| Узел | Высота слева | Высота справа | Результат |
|---:|---:|---:|---|
| 4 | 0 | 0 | высота 1 |
| 3 | 1 | 0 | высота 2 |
| 2 | 2 | 0 | разница 2, возвращается -1 |
| 1 | — | — | сигнал -1 передаётся вверх, ответ False |

Даже если высоты левого и правого поддеревьев корня одинаковы, дисбаланс в
узлах `2` и `5` делает всё дерево несбалансированным.

### Тесты

Проверяются пустое и одноузловое деревья, сбалансированное дерево, допустимая
разница высот ровно один, вырожденное дерево и случай, когда поддеревья корня
одинаковой высоты, но внутри одного из них существует дисбаланс.
